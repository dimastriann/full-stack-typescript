# Support

Use the repository's public issue tracker for reproducible bugs and focused feature requests. Include the application version, environment, reproduction steps, expected behavior, actual behavior, and relevant sanitized logs.

Use discussions, when enabled, for setup questions and design proposals. Security concerns must follow [SECURITY.md](SECURITY.md).

Community support is provided on a best-effort basis. Commercial support and service-level commitments are not currently offered from this repository.
